# Digital Studio

Prototipo navigabile della landing page **Digital Studio**.

**Proposta di valore:** soluzioni digitali su misura senza costruire un team interno. Consulenti dedicati, rete di specialisti, AI, analisi, sviluppo ed evoluzione continuativa.

## Avvio locale

Apri `index.html` con un browser o usa un server statico:

```bash
python3 -m http.server 8080
```

## Pubblicazione con GitHub Pages

1. Carica i file nella root del repository `giusebuild/digital-studio`, branch `main`.
2. In GitHub apri **Settings → Pages**.
3. Seleziona **Deploy from a branch**, branch `main`, cartella `/ (root)` e salva.
4. URL previsto, dopo l'attivazione: https://giusebuild.github.io/digital-studio/

## Stato

- Prototipo interattivo responsive, con navigazione e scelta dello stato del progetto.
- **Il form contatti è una demo: non invia email né salva dati.**
- Fee iniziale, canone mensile ed eventuale quota sui risultati sono un modello indicativo, senza prezzi definitivi.
- Nessuna integrazione backend o trattamento dati effettivo.
