# Digital Studio

Sito dimostrativo di Digital Studio, un concept di partner esterno per le esigenze digitali delle imprese.

**Posizionamento:** consulenza, coordinamento e progetti digitali. Le imprese possono ricevere supporto per prendere decisioni, organizzare le competenze necessarie e affrontare interventi digitali, anche attraverso un rapporto continuativo.

## Pagine

- [Homepage](https://giusebuild.github.io/digital-studio/) — proposta di valore per le imprese, problemi ricorrenti, quattro linee di servizio, esempio illustrativo, metodo, fiducia, FAQ e contatti.
- [Partner](https://giusebuild.github.io/digital-studio/partner/) — collaborazione professionale, sviluppo commerciale reciproco e modalità di coinvolgimento nella rete.

## Stack

Sito statico in HTML, CSS e JavaScript senza framework, tracciamenti, dipendenze esterne o servizi cloud aggiuntivi.

```text
index.html
partner/index.html
assets/styles.css
assets/site.js
assets/icon.svg
```

Puoi aprire `index.html` nel browser oppure eseguire un server locale:

```bash
python3 -m http.server 8080
```

## Pubblicazione

GitHub Pages dal branch `main`, cartella `/ (root)`, tramite **Settings → Pages** del repository.

## Limiti del prototipo

- **I moduli contatto sono dimostrativi**: validano i campi e permettono di copiare o salvare un riepilogo. **Non inviano email e non raccolgono richieste.**
- Non sono dichiarati clienti, case study, partner, prezzi o risultati commerciali non verificati. L'esempio del gestionale è esplicitamente illustrativo.
- Il servizio continuativo, il pricing, l'ICP e le collaborazioni effettive richiedono validazione commerciale.
- Prima di aprire un form reale è necessario definire un canale di contatto, informativa privacy e relativo trattamento dei dati.

Il sito ha funzione di prototipo pubblico di posizionamento: non sostituisce ancora un'offerta commerciale formalizzata.
